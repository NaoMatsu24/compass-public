# Compass 公開用

個人の受験日・目標スコア・履修科目・候補大学を含まないアプリ本体です。
設定の「JSONを読み込む」から、手元のバックアップを復元できます。復元は現在の端末のデータを置き換えます。
保存キー: compass.study-abroad.v1。データは端末・ブラウザ・アクセス先ごとに保存され、自動同期されません。

新しい公開リポジトリに、このフォルダの中身をアップロードしてください。index.htmlをリポジトリ直下に置きます。
バックアップJSONや個人用設定はアップロードしないでください。古いリポジトリは非公開のままにします。
キャラクター画像は公開用に含まれています。


## Googleアカウントで自動同期
設定 → Googleログインを準備 → Googleでログイン。最初の端末では最新記録があることを確認し「この端末のデータを使う」、2台目以降は「クラウドのデータを使う」を選びます。
オンラインでの保存後、およびアプリ表示中は約30秒ごと・画面復帰時・ネットワーク復帰時に同期します。オフライン中は従来のlocalStorageを利用します。
別々の端末で変更が重なった場合はデータ全体を自動統合せず、同期を一時停止して選択を求めます。選択前の両方の記録は端末内の同期前バックアップに保管します。設定から直前のJSONを書き出して従来の読み込みで復元できます。
同期の停止・ログアウト後も端末の学習記録は残ります。共有端末での利用には適していません。
Firestoreには users/{本人のUID}/compass/state に版番号とJSONを保存し、トランザクションで古い版からの上書きを防ぎます。同期上限はUTF-8で900000バイト、超過時はローカル保存とJSON書き出しを継続できます。
APIキーはWeb接続用で、秘密鍵ではありません。Firestoreのアクセス制限はFirebaseコンソールで設定します。サービスアカウント秘密鍵やバックアップを公開フォルダへ追加しないでください。
初回Googleログインはオンラインで行います。iPad/Safariでポップアップがブロックされる場合は許可し、ホーム画面からのログインも実機で確認してください。Firebase外部SDKが取得できなくても、学習記録はローカルで利用できます。
